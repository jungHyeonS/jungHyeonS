## 서정현 | Frontend Engineer

MAU 50만+ 심리테스트 플랫폼, MAU 60만+ 게임 어시스턴트 데스크톱 앱, EdTech SaaS 등 다양한 규모의 서비스를 설계·개발·운영해 왔습니다.

- Performance API 기반 RUM SDK 직접 개발 + Grafana/Loki 모니터링 구축
